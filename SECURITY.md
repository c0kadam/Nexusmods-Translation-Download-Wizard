## Güvenlik Notları

- Nexus API anahtarınızı yalnızca uygulama içindeki alana girin.
- API anahtarı, NXM anahtarı, cookie ve indirme URL'lerini paylaşmayın.
- Araç bu bilgileri loglara veya raporlara yazmamak üzere tasarlanmıştır.
